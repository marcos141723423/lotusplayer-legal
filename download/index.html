Como instalar pela TV

  3. No campo de endereço, digite:
    marcos141723423.github.io/lotusplayer-legal/download/lotusplayer.apk
    e clique em Go.
  4. Quando o download terminar, clique em Instalar. Se a TV disser que não pode instalar apps desta fonte, veja a seção abaixo.

Se essa opção não aparecer (comum na Google TV), ative antes o modo desenvolvedor: em Configurações › Sistema › Sobre, clique 7 vezes seguidas no item do build do sistema (o nome varia, por exemplo "Build do SO do Android TV") até aparecer o aviso de que você agora é desenvolvedor.

Se o Google Play Protect avisar que não reconhece o app, é só porque ele não veio da Play Store. Escolha Mais detalhes › Instalar mesmo assim.

How to install from the TV

  1. On the TV, open the Play Store, search for Downloader (by AFTVnews) and install it.
  2. Open Downloader. If it asks for access to files, choose Allow.
  3. In the address field, type:
    marcos141723423.github.io/lotusplayer-legal/download/lotusplayer.apk
    and click Go.
  4. When the download finishes, click Install. If the TV says it can't install apps from this source, see the section below.
  5. Click Open. Downloader offers to delete the downloaded file: you can delete it, the app stays installed.

Lotus Player then shows up in the TV's app list.

First sign-in

Open Lotus Player and enter your access username and password. Don't have one yet? Ask for a free trial on WhatsApp +55 (31) 98357-7732 or point your phone's camera at the QR code on the sign-in screen.

If the TV blocks the installation

Allow Downloader under Settings › Apps › Security & restrictions › Unknown sources. On older TVs, the path is Settings › Device Preferences › Security & restrictions › Unknown sources.

If that option is missing (common on Google TV), turn on developer mode first: under Settings › System › About, click the system build item (for example "Android TV OS build") 7 times in a row until you see that you are now a developer.

If Google Play Protect says it doesn't recognize the app, that's only because it didn't come from the Play Store. Choose More details › Install anyway.

Updating

When a new version comes out, download it from the same address and install it over the old one. Your access details, favorites and "Continue watching" are kept.
